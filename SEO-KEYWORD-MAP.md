## Implementation rules

1. Each indexable page has one distinct primary intent. Do not make multiple pages compete for the same exact phrase.
2. Use the primary phrase naturally in the title, H1 or opening copy, and relevant internal-link text. Use supporting phrases only where the content genuinely covers them.
3. Keep Lahore modifiers on local service and supplier pages. Use Pakistan-wide wording only where delivery and service scope support it.
4. Do not publish thin doorway pages for every product or city. Create a new landing page only when it can provide genuinely useful scope, specifications, FAQs, project evidence and contact guidance.
5. Review Search Console queries after indexing and refine this map using actual impressions, clicks, average position and inquiry conversions.
6. Do not promise rankings or insert unverified search-volume estimates.
